# HexWiki compiler guide

This installed package resource defines the shared wiki evidence contract.

- Treat every compiled claim as an unverified, source-bounded draft.
- Cite exact PDF-page gateways beside the claims they support.
- Keep reported material, source attribution, interpretation, and compiler
  inference distinct.
- State evidence limits explicitly; inclusion is never verification.
- Do not consult a prior, reference, comparison, or gold wiki while generating.

The complete subject-neutral model writing workflow is added with the guarded
generation runtime. The deterministic source guides and validators already
enforce the source, locator, metadata, and integrity portions of this contract.
